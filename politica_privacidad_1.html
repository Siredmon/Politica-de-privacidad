Politica de Privacidad

Drywall Calculadora

Ultima actualizacion: abril 2026

Esta Politica de Privacidad describe como Drywall Calculadora recopila, usa y protege la informacion de sus usuarios. Al usar esta aplicacion, aceptas los terminos descritos en este documento.

1. Informacion que recopilamos

Drywall Calculadora puede recopilar los siguientes tipos de informacion:

  • Imagenes de camara o galeria: Unicamente cuando el usuario utiliza la funcion "Foto a Presupuesto". Las imagenes se envian a la API de Google Gemini para analisis y no se almacenan en nuestros servidores.
  • Datos de uso anonimos: A traves de Google AdMob, se pueden recopilar datos anonimos de uso para mostrar publicidad relevante.
  • Datos locales: Los calculos, precios y el historial se almacenan unicamente en el dispositivo del usuario y no se transmiten a ningun servidor externo.

2. Uso de la camara

La aplicacion solicita permiso de acceso a la camara y galeria de fotos unicamente para la funcion de estimacion de medidas con inteligencia artificial. El acceso se solicita solo cuando el usuario decide usar esta funcion. Las imagenes capturadas:

  • Se envian de forma segura a la API de Google Gemini para analisis de medidas
  • No se almacenan en nuestros servidores ni en bases de datos externas
  • No se comparten con terceros distintos a Google Gemini para el proposito descrito
  • Se procesan en tiempo real y no se retienen despues del analisis

3. Publicidad (Google AdMob)

Drywall Calculadora utiliza Google AdMob para mostrar anuncios. AdMob puede recopilar y usar datos para personalizar los anuncios mostrados. Esto incluye:

  • Identificadores de dispositivo
  • Datos de uso anonimos
  • Informacion de ubicacion aproximada (si el usuario lo permite)

Para mas informacion sobre como Google usa estos datos, visita: https://policies.google.com/privacy

Los usuarios pueden optar por no recibir anuncios personalizados en la configuracion de su dispositivo Android en: Ajustes > Google > Anuncios > Inhabilitar personalizacion de anuncios.

4. Almacenamiento local de datos

La siguiente informacion se almacena unicamente en el dispositivo del usuario:

  • Historial de calculos realizados
  • Precios de materiales configurados por el usuario
  • Preferencias de la aplicacion

Estos datos no se transmiten a ningun servidor externo y el usuario puede eliminarlos en cualquier momento desde la aplicacion o desinstalando la app.

5. Servicios de terceros

Drywall Calculadora utiliza los siguientes servicios de terceros:

  • Google AdMob: Para mostrar publicidad. Politica de privacidad: https://support.google.com/admob/answer/6128543
  • Google Gemini API: Para el analisis de imagenes en la funcion de IA. Politica de privacidad: https://policies.google.com/privacy

6. Permisos de la aplicacion

Drywall Calculadora solicita los siguientes permisos:

  • CAMARA: Para capturar fotos en la funcion "Foto a Presupuesto"
  • READ_EXTERNAL_STORAGE / MEDIA_IMAGES: Para seleccionar imagenes de la galeria
  • INTERNET: Para mostrar anuncios y usar la funcion de IA

7. Privacidad de menores

Drywall Calculadora no esta dirigida a menores de 13 anos. No recopilamos intencionalmente informacion personal de menores. Si eres padre o tutor y crees que tu hijo ha proporcionado informacion personal, contactanos para eliminarla.

8. Seguridad

Nos comprometemos a proteger la informacion del usuario. Los datos locales se almacenan de forma segura en el dispositivo. Las comunicaciones con APIs externas se realizan mediante conexiones HTTPS cifradas.

9. Cambios en esta politica

Podemos actualizar esta Politica de Privacidad periodicamente. Te notificaremos de cualquier cambio publicando la nueva politica en esta pagina y actualizando la fecha de "ultima actualizacion". Te recomendamos revisar esta politica periodicamente.

10. Tus derechos

Como usuario tienes derecho a:

  • Acceder a los datos almacenados localmente en tu dispositivo
  • Eliminar todos los datos de la app desinstalando la aplicacion
  • Optar por no recibir anuncios personalizados
  • Contactarnos para cualquier consulta sobre privacidad
